# VOP Ingest — update feed

This repository exists so [VOP Ingest](https://github.com/VoiceOfProphecy/vop-ingest)
can check for updates. It holds `appcast.xml` and the released builds.

The application source lives in a separate private repository. Nothing here is
meant to be edited by hand — `release.sh` in the source repo regenerates and
publishes this feed.
